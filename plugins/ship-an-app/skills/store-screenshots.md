applies: work on store listing or screenshots
---

# When to use
Planning or refreshing App Store or Google Play screenshots.

# How
1. Pick five screens at most, in the order a new person would care: the main job first, then what makes it different.
2. Give each a caption of four to six words that says a benefit, not a feature name.
3. Use real-looking content, never lorem ipsum, and nothing private.
4. List the sizes the store needs for the devices the app supports.
5. Put the plan in the work item before making anything, so the person can change the order.

# Check before handing over
- Captions read as one story from left to right.
- Light and dark versions only if the app's listing uses both.
